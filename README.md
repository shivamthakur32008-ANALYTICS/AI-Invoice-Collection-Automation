# AI-Invoice-Collection-Automation

## Overview

An AI-powered Invoice Collection Automation System built with n8n.

This project automates:

- Invoice Intake
- AI Risk Scoring
- Daily Payment Reminders
- Payment Detection
- Centralized Invoice Tracking

## Features

- AI Risk Scoring
- Duplicate Invoice Detection
- Email Reminder Engine
- WhatsApp Ready
- Payment Detection
- Automated Logging
- Scheduled Workflows

- ## Technologies

- n8n
- OpenAI
- Gmail
- HTTP API
- Data Tables
- JavaScript
